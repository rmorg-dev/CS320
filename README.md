# CS320
## 1. How can I ensure that my code, program, or software is functional and secure?
  I make sure it is functional through testing. Running tests on code not only make sure it fits within the requirements laid out by the customer, but also ensures that code works correctly without directly interacting with in the in console. To make sure my code is secure, I follow best practices for code. This means using data encapsulation to hide things like data structures or variables that change the information within the class. 
## 2. How do I interpret user needs and incorporate them into a program?
When interpreting user needs, I try to focus on the negative aspects they don't want first. In this project specifically, I made sure I focused on the limitations the customer wanted such as character limits or non null variables. This allows me to make tests that specifically targets these areas. After that, I focus on the general functionality the customer wants. 
## 3. How do I approach designing software?
When designing software, I typically use Test Driven Development. This allows me to make sure I meet customer requirements as well as check for specific edge cases that could cause the final product to be insecure or function differently than what was requested by the customer.
